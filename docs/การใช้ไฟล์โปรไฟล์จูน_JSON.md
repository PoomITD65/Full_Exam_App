# การใช้ไฟล์โปรไฟล์จูน JSON
ไฟล์ `docs/โปรไฟล์แนะนำการจูน_OMR.json` รวมชุดค่าที่แนะนำและสูตรคำนวณที่ตัวอ่านใช้
## โครงสร้างหลัก
- `profiles.current_from_code` ค่าตั้งต้นปัจจุบันจากโค้ด
- `profiles.recommended_bestfit` โปรไฟล์สำหรับภาพซีด/เส้นไม่คมมาก
- `formulas.*` สูตรคำนวณสำหรับ threshold และขนาดหน้าต่าง/หน้ากาก
## วิธีนำไปใช้
- อัปเดตค่าที่ต้องการ แล้วปรับโค้ดใน `backend/typhoon-grader/app.py` ให้โหลดจากไฟล์ภายนอก หรือแมพค่าเข้า constant
- ทดสอบกับชุดภาพจริง และเก็บไฟล์เวอร์ชันแยกตามสภาพงาน/เครื่องถ่าย
