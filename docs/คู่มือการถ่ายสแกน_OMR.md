# คู่มือการถ่าย/สแกน OMR ให้ได้ผลดี
## หลักการสำคัญ
- ให้กรอบทั้งสี่มุมของบัตรคำอยู่ในเฟรมชัดเจน
- แสงสว่างสม่ำเสมอ ลดเงาและแสงสะท้อน
- หลบพื้นหลังมีลาย/สีตัดกันแรง
## การถ่ายด้วยมือถือ
- จับเครื่องให้นิ่ง ระยะพอให้กรอบพอดีเฟรม
- อนุญาตเอียงได้เล็กน้อย ตัวอ่านจะ warp ให้อัตโนมัติ
## การสแกนจากไฟล์
- ใช้ความละเอียดกลางถึงสูง (≥ 150–300 DPI) ไฟล์ JPEG/PNG
- หลีกเลี่ยงการครอปจนขาดกรอบนอก
## เมื่ออ่านเพี้ยนบ่อย
- อ้างอิง “คู่มือปรับจูน OMR (สั้น/ฉบับเต็ม)” ในโฟลเดอร์ `docs/`
- พิจารณาปรับพารามิเตอร์ตาม `docs/โปรไฟล์แนะนำการจูน_OMR.json`
