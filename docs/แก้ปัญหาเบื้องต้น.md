# แก้ปัญหาเบื้องต้น
## แอปล็อกอินไม่ได้
- ตรวจ `API_BASE_URL` และสิทธิ์ CORS ของ backend
- เช็ก DB ให้มีผู้ใช้และ `IsUse = 1`
## อัปโหลด OMR แล้วได้คะแนนผิด/ไม่อ่าน
- ตรวจคุณภาพรูป: กรอบครบ แสงสม่ำเสมอ ไม่มีเงาบัง
- ปรับพารามิเตอร์ตามคู่มือจูน (projection_k, half_size_factor, ring_*, min_fill_ratio)
- ตรวจคีย์เฉลย `backend/typhoon-grader/answer_key.json`
## บันทึกลงฐานข้อมูลไม่สำเร็จ
- ดูคอลัมน์ตาราง `tblAcdQuizResult` ว่ามี/ชนิดข้อมูลตรงกับที่ upsert หรือไม่
- ดู log/รายละเอียด SQL ในผลตอบกลับจาก `/omr/grade`
