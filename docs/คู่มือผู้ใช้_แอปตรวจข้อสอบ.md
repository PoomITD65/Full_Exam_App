# คู่มือผู้ใช้ (แอปตรวจข้อสอบ)
เอกสารนี้อธิบายการใช้งานตั้งแต่ล็อกอิน อัปโหลด OMR จนถึงดูผลสรุปอย่างย่อ เหมาะสำหรับผู้สอน/ผู้คุมสอบที่ใช้งานประจำวัน
## เริ่มต้นใช้งาน
- ล็อกอินด้วยชื่อผู้ใช้/รหัสผ่านจากระบบกลาง
- เซ็ต API ให้ชี้ไปยังเซิร์ฟเวอร์ที่ใช้งานจริง ดูวิธีใน `exam/lib/app/services/api_service.dart`
## หน้าหลัก (Home)
- แสดงชุดข้อสอบล่าสุดของฉัน สถานะตรวจแล้ว/คงเหลือ และปุ่มเข้า Scan
- ดูสรุปรายวัน/แยกชุดข้อสอบได้
## สแกน/อัปโหลด OMR
- ไปที่เมนู Scan เลือกชุดข้อสอบ (Term/Year ถูกดึงอัตโนมัติ)
- ถ่ายภาพบัตรคำหรือเลือกจากคลัง แล้วระบบจะส่งไปตรวจที่ backend
- เมื่อสำเร็จ จะแจ้ง StdNo/ห้อง/คะแนน หากบันทึก DB แล้วจะขึ้นสถานะ “ตรวจแล้ว” ในรายการ
## ดูผลรายคน
- ค้นหาผลรายคนได้ที่เมนู Result หรือจากสรุป คลิกรายชื่อนักเรียนเพื่อดูรายละเอียดและรูป (ถ้ามี)
## โปรไฟล์ผู้ใช้
- แก้ไขข้อมูลพื้นฐาน รูปภาพ ติดต่อ อื่นๆ ได้ที่เมนู Profile
## เคล็ดลับใช้งานเร็ว
- ถ่ายให้กรอบทั้งสี่มุมอยู่ในเฟรม และแสงสม่ำเสมอ
- รูปเอียงเล็กน้อยได้ แต่หลีกเลี่ยงเงาทับช่องคำตอบ
- ถ้าอ่านพลาดบ่อย ให้ดูคู่มือ “การถ่าย/สแกน OMR” และ “การจูนแกน/พารามิเตอร์”
