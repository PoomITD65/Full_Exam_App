# คู่มือติดตั้งระบบ Full Exam App

เอกสารนี้รวบขั้นตอนติดตั้งทั้ง Backend (FastAPI + OMR) และ Frontend (Flutter) แบบสั้น กระชับ พร้อมคำสั่งใช้งานจริงบน Windows/macOS/Linux

## 1) โครงสร้างระบบโดยสรุป
- Backend: FastAPI (`backend/`) เชื่อม MySQL และเรียกตัวอ่าน OMR (`backend/typhoon-grader/app.py`)
- Frontend: Flutter (`exam/`) ใช้งาน API ผ่าน `API_BASE_URL`
- เอกสารจูนการอ่าน OMR อยู่ใน `docs/`

## 2) สิ่งที่ต้องมี (Prerequisites)
- Git, Python 3.11 (แนะนำ 64-bit)
- MySQL Server 8.x (หรือ MariaDB ที่เข้ากันได้)
- Flutter SDK (ช่องทางทางการ) + Android Studio (สำหรับ Android) + Xcode (ถ้าต้องการ iOS)
- บน Windows: PowerShell 7+, แนะนำติดตั้งผ่าน winget/choco ตามสะดวก

ตัวอย่างติดตั้งพัสดุพื้นฐาน
- Ubuntu/Debian
  - `sudo apt update && sudo apt install -y python3.11 python3.11-venv python3-pip mysql-server`
- macOS (Homebrew)
  - `brew install python@3.11 mysql`
- Windows (PowerShell มี Python แล้วข้ามได้)
  - ติดตั้ง MySQL จากตัวติดตั้งทางการ หรือ `choco install mysql`

## 3) เตรียมฐานข้อมูล
1) เข้าระบบ MySQL แล้วสร้างฐาน/ผู้ใช้ (ตัวอย่าง)
```
CREATE DATABASE exam_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'exam_user'@'%' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON exam_db.* TO 'exam_user'@'%';
FLUSH PRIVILEGES;
```
2) เตรียมสคีมาที่ระบบใช้ (ตารางเช่น `tblAcdQuiz`, `tblAcdQuizResult`, `tblAcdQuizChoice`, `tblUsers` ฯลฯ) ให้พร้อมในฐาน `exam_db`
- หากมีสคีมาจริงอยู่แล้ว ให้ชี้ config ไปยังฐานนั้นได้ทันที

## 4) ตั้งค่าและรัน Backend (FastAPI)
จากโฟลเดอร์รากโปรเจกต์
```
python -m venv .venv
# Windows
.\.venv\Scripts\Activate.ps1
# macOS/Linux
source .venv/bin/activate

pip install -r backend/requirements.txt
```
สร้างไฟล์ `.env` ที่ `backend/.env`
```
DB_HOST=localhost
DB_PORT=3306
DB_USER=exam_user
DB_PASSWORD=your_password
DB_NAME=exam_db
DB_CHARSET=utf8mb4

JWT_SECRET=change-this-secret
```
รันเซิร์ฟเวอร์
```
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
หมายเหตุ: การรันจากโฟลเดอร์รากทำให้ import `backend.*` ถูกต้อง

## 5) รัน Frontend (Flutter)
เข้าโฟลเดอร์ `exam/` แล้วติดตั้งพัสดุ
```
flutter pub get
```
รันและกำหนด API ให้ชี้ไปยัง Backend
```
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
```
ตัวอย่างเลือกอุปกรณ์
- Android: เปิดอีมูเลเตอร์/เสียบเครื่องจริง แล้ว `flutter devices` ตรวจสอบ ก่อน `flutter run`
- Web (Chrome): `flutter run -d chrome --dart-define=API_BASE_URL=http://127.0.0.1:8000`

สิทธิ์กล้อง (Android)
- ตรวจไฟล์ `exam/android/app/src/main/AndroidManifest.xml` ว่ามี
```
<uses-permission android:name="android.permission.CAMERA" />
```
และโค้ดหน้า Scan ใช้แพ็กเกจ `camera`/`image_picker` พร้อมจัดการ Runtime Permission ตามแนวปฏิบัติของ Flutter

## 6) ทดสอบระบบอย่างเร็ว
ทดสอบอัปโหลด OMR โดยตรง (ต้องมี Backend ทำงานที่พอร์ต 8000)
```
curl -X POST "http://127.0.0.1:8000/omr/grade" \
  -F "quizId=123" -F "term=1" -F "year=2025" -F "grader=teacherA" \
  -F "file=@D:/path/to/omr.jpg;type=image/jpeg"
```
หมายเหตุ: `quizId/term/year` ควรตรงกับข้อมูลในตาราง `tblAcdQuiz`

## 7) ปรับจูน OMR (ถ้าภาพอ่านเพี้ยน)
- อ่านคู่มือจูน: `docs/คู่มือปรับจูน_OMR_ฉบับสั้น.md` และ `docs/คู่มือปรับจูน_OMR_ฉบับเต็ม.md`
- ใช้โปรไฟล์แนะนำ: `docs/โปรไฟล์แนะนำการจูน_OMR.json`
- แนวทางโหลดค่าโปรไฟล์เข้าสู่ตัวอ่าน ดูตัวอย่างโค้ดที่แนบในสองไฟล์คู่มือข้างต้น

## 8) ปัญหาที่พบบ่อย
ดู `docs/แก้ปัญหาเบื้องต้น.md` สำหรับแนวทางตรวจสอบเบื้องต้น (ล็อกอิน/อัปโหลด/บันทึก DB)

---
Tip: คงไฟล์ `.env` แยกจากซอร์สโค้ด และใช้ `--dart-define` สำหรับ Frontend เพื่อสลับ Backend ระหว่าง dev/prod ได้สะดวก
